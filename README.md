# Engineering Simulation Courses

Learn practical OpenModelica and Simscape modeling and simulation skills, from beginner fundamentals to advanced system modeling.

## Course 1: Introduction to OpenModelica
Build a strong foundation and start creating your own simulations.

**Who this course is for:**  
- Beginners in modeling and simulation  
- Students and engineers wanting practical OpenModelica experience  

**Skills you’ll gain:**  
- Using OMEdit graphical interface efficiently 
- Building and simulating simple systems  
- Defining parameters, variables, and equations  
- Running dynamic simulations and analyzing results
